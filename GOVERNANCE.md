# Governance

## Maintainer

AgentForge has one maintainer, the repository owner. The maintainer decides what is merged and
released, and what goes on the [roadmap](ROADMAP.md).

## How changes happen

- Propose changes through an issue or a pull request. The maintainer reviews every pull request
  before it is merged.
- A milestone starts only when the maintainer approves it. Planned milestones in ROADMAP.md are
  direction, not approval.
- The roadmap changes only through an edit to ROADMAP.md.
- Contributions follow [CONTRIBUTING.md](CONTRIBUTING.md).

## AI agents

AI coding agents, such as Claude Code, work on this repository only at the maintainer's request.
Without the maintainer's explicit permission for that specific action, an agent may not:

- commit, push, merge, or rewrite Git history;
- approve its own or anyone else's work;
- deploy, publish, or send messages outside the repository;
- run anything that spends money, such as the billed live Claude Code test.

AgentForge applies the same rule to its own workers: models suggest, but deterministic code and a
human decide.
