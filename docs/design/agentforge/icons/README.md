# Icons

24×24 grid, 2px round stroke, drawn in `ink` (#0f172a) in these files. In the app they are inline SVGs with `stroke="currentColor"` so they take the colour of their text: a badge's `*-ink`, or a group's `*-edge` on neutral grounds. Render at 16px. Always beside a text label, `aria-hidden="true"`.

| File | Use |
|---|---|
| `needs-you.svg` | Needs you (Awaiting approval; Interrupted run). |
| `working.svg` | Working (Assigned, Running, Validating; Active run). Static arc, never spun. |
| `waiting.svg` | Waiting (Pending, Ready). |
| `held.svg` | Held (Paused); also the Pause button. |
| `done.svg` | Done (Completed). |
| `problem.svg` | Problem (Failed, Blocked); refusal and error alerts. |
| `stopped.svg` | Stopped (Cancelled). |
| `finished.svg` | Finished run (neutral). |
| `connected.svg` | Status bar: Connected (circle with a check, in `done-ink`). |
| `connecting.svg` | Status bar: Connecting. |
| `offline.svg` | Status bar: Offline, Token refused, Server error. |
| `no-token.svg` | Status bar: No token. |
| `resume.svg` | Resume button. |
| `retry.svg` | Retry and Recover run buttons. |
| `cancel.svg` | Cancel buttons. |
| `approve.svg` | Approve diff button. |
| `reject.svg` | Reject diff button. |
| `chevron.svg` | Attempt disclosure; rotates 90° when open. |
| `copy.svg` | Copy run id or diff. |
