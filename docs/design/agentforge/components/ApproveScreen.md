# ApproveScreen

The decision part of a plan in the whole window. Wide, in the Technical view: every task's More options starts open, so attempts, time limits and "run the checks itself" are all visible at once. Narrow, in the Plain view: the server's refusal quoted under Approve and start, and the reject form under it. This is where MoreOptions matters most; see MoreOptions, TaskRights and PlanPage.

- Technical changes only which folds start open. Nothing else moves, so a person who switches views finds every control where it was.
- The refusal stays until the next approve; the rights and the typed reject reason are kept.
