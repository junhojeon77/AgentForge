# PlanScreen

The whole window with a plan waiting for the person's OK: wide at its top (header, the folded fixes, the tasks), narrow scrolled down to Approve and start in the Plain view, where nothing is ticked yet and the "no task may change files" notice shows. See PlanPage and TaskRights.

- The plan's id is selected in the Plans tab, which carries the waiting count.
- In the narrow window the task cards drop to one column and the rights table stacks each row.
