AgentForge can't reach its server

The app shows your runs once the local AgentForge server is running on this machine. It checks again every 2 seconds.

  1. Open a terminal in your AgentForge folder.
  2. Start the server:
    python -m agentforge serve
  3. Leave it running. This window connects by itself, or press Reconnect.
